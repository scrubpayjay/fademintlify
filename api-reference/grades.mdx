---
title: "GET /grades — Forecast Grading Status and Outcomes"
sidebarTitle: "GET /grades"
description: "Retrieve grading status and settled outcomes for all forecasts — pending, graded, voided, and unavailable — with misses always present alongside hits."
---

The `/grades` endpoint returns every current forecast paired with its grading status and, when the grading status is `"graded"`, the venue-settled binary outcome and the timestamp of that grading event. You can filter by `status`, `family`, `sport`, and `date` to narrow results to a specific slice of the graded record. Every grade record is returned regardless of outcome — misses (`outcome = 0`) are never suppressed and always appear alongside hits (`outcome = 1`). Treating misses as a filter target in your analysis pipeline will bias any calibration or accuracy calculation you perform.

<Warning>
  Misses (`outcome = 0`) are always included in `/grades` responses and are never filtered out by the API. If you build a downstream aggregation that excludes `outcome = 0` records — even unintentionally, for example by filtering for `outcome > 0` — your win rate and calibration metrics will be overstated. Always process all returned records.
</Warning>

## Query Parameters

<ParamField query="sport" type="string" optional>
  Filter to grades for a specific sport, for example `"nfl"` or `"nba"`. Matches the sport associated with each forecast's market. Omit to return grades across all sports.
</ParamField>

<ParamField query="family" type="string" optional>
  Filter to a specific prediction family, for example `"nfl_spreads"`. Matches the `family` field on the underlying forecast. Omit to return grades across all families.
</ParamField>

<ParamField query="status" type="string" optional>
  Filter by grading status. Accepted values: `"pending"`, `"graded"`, `"void"`, `"unavailable"`. Omit to return records in all statuses.
</ParamField>

<ParamField query="date" type="string" optional>
  Filter to grades whose underlying forecast has an `inputs_as_of` timestamp on the given UTC calendar date. Format: `YYYY-MM-DD`, for example `"2025-09-14"`. Omit to return grades across all dates.
</ParamField>

<ParamField query="limit" type="integer" optional>
  Number of records per page. Accepts integers from `1` to `200`. Defaults to `50`.
</ParamField>

<ParamField query="cursor" type="string" optional>
  Opaque pagination cursor from a previous response's `next_cursor` field. Omit on the first request.
</ParamField>

## Response Fields

<ResponseField name="api_version" type="string">
  Always `"1"`.
</ResponseField>

<ResponseField name="data" type="object[]">
  Array of Grade objects. Returns an empty array if no grades match the filters.

  <Expandable title="Grade object fields">
    <ResponseField name="forecast_id" type="string (uuid)">
      The Sportshack UUID of the forecast this grade is attached to. Use this to join back to the full forecast record via `GET /forecasts/{forecastId}`.
    </ResponseField>
    <ResponseField name="family" type="string | null">
      Sportshack prediction family inherited from the forecast, for example `"nfl_spreads"`. `null` if the underlying market is unclassified.
    </ResponseField>
    <ResponseField name="outcome" type="integer | null">
      The venue-settled binary outcome. `1` indicates the YES side resolved (a hit). `0` indicates the NO side resolved (a miss). `null` when `grading_status` is not `"graded"` — for example, when the grade is pending or the outcome is unavailable.
    </ResponseField>
    <ResponseField name="grading_status" type="string">
      The current grading state of this forecast. One of four values:

      - `"pending"` — the underlying event has not yet concluded or the venue has not yet settled the market.
      - `"graded"` — the venue has settled the market and Sportshack has recorded the outcome. `outcome` will be `0` or `1`.
      - `"void"` — the market was voided by the venue before settlement; no outcome is recorded.
      - `"unavailable"` — the grading data could not be retrieved or is not available for this market.
    </ResponseField>
    <ResponseField name="graded_at" type="datetime | null">
      UTC ISO-8601 timestamp of when Sportshack recorded the grading event. `null` when `grading_status` is not `"graded"`.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="next_cursor" type="string | null">
  Opaque cursor for the next page of results. `null` when you have reached the last page.
</ResponseField>

## Examples

**Retrieve all graded outcomes:**

```bash
curl -s "https://fade.sportshack.ai/api/v1/grades?status=graded" \
  -H "Authorization: Bearer fade_live_YOUR_KEY_HERE"
```

**Filter by family and date:**

```bash
curl -s "https://fade.sportshack.ai/api/v1/grades?family=nfl_spreads&date=2025-09-14" \
  -H "Authorization: Bearer fade_live_YOUR_KEY_HERE"
```

**Check pending grades for a specific sport:**

```bash
curl -s "https://fade.sportshack.ai/api/v1/grades?sport=nba&status=pending" \
  -H "Authorization: Bearer fade_live_YOUR_KEY_HERE"
```
