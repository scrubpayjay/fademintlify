title: "GET /download — Bulk Export Forecasts or Grades"
sidebarTitle: "GET /download"
description: "Bulk-export forecasts or grades as a JSON or CSV file, capped at 50,000 rows. Requests over the cap return 422 — there is no silent truncation."
---

The `/download` endpoint delivers the same data as `GET /forecasts` and `GET /grades` as a file attachment rather than a paginated JSON feed, making it suited for batch ingestion, offline analysis, and nightly data pulls. You choose the dataset (`forecasts` or `grades`) and the output format (`json` or `csv`), then narrow results with `family` and `date` filters. The endpoint enforces a hard cap of 50,000 rows per request — if your filter combination would return more rows than the cap allows, the API returns a `422` error asking you to narrow your filters. There is no silent truncation; you will always know if your request exceeded the limit.

<Warning>
  The 50,000-row cap is hard. Requests that would produce more than 50,000 rows return a `422 Unprocessable Entity` response, never a partial file. Always use `family` and `date` together when exporting a high-volume dataset to stay under the cap.
</Warning>

<Tip>
  Combining `family` with a specific `date` is the most reliable way to stay under the row cap. For example, a single family on a single game date rarely exceeds a few hundred rows, giving you a comfortable safety margin even for the largest NFL Sundays.
</Tip>

## Query Parameters

<ParamField query="dataset" type="string" required>
  The dataset to export. Accepted values: `"forecasts"` or `"grades"`. This parameter is required.
</ParamField>

<ParamField query="format" type="string" optional>
  Output format for the file attachment. Accepted values: `"json"` or `"csv"`. Defaults to `"json"` if omitted. CSV output uses standard comma-separated values with a header row; string fields containing commas are quoted.
</ParamField>

<ParamField query="family" type="string" optional>
  Filter the export to a specific prediction family, for example `"nfl_spreads"`. Strongly recommended when exporting large datasets to stay under the 50,000-row cap.
</ParamField>

<ParamField query="date" type="string" optional>
  Filter to records whose underlying `inputs_as_of` timestamp falls on the given UTC calendar date. Format: `YYYY-MM-DD`, for example `"2025-09-14"`. Use together with `family` to keep exports narrow.
</ParamField>

## Response

A successful `200` response returns a file attachment with the `Content-Disposition: attachment` header. The response body contains a JSON or CSV file depending on the `format` parameter.

<ResponseField name="row_count" type="integer">
  Total number of data rows included in the export file. For JSON format, this field appears at the top level of the response envelope. For CSV format, it is included as a comment in the file header.
</ResponseField>

<ResponseField name="data" type="object[] | string">
  For JSON format: an array of Forecast or Grade objects matching the same field schema as the `/forecasts` and `/grades` endpoints respectively. For CSV format: the file contents as rows, with a header line matching field names. The same field exclusions apply — no venue prices, verbatim rules text, or order book data is included.
</ResponseField>

<Note>
  The same field exclusions that apply to `/forecasts` and `/grades` apply here. The `/download` endpoint does not grant access to additional data. No venue prices, contract text, or any other field outside the analytical license boundary is present in the exported file.
</Note>

## Examples

**Export all forecasts for a family on a specific date as JSON:**

```bash
curl -s "https://fade.sportshack.ai/api/v1/download?dataset=forecasts&family=nfl_spreads&date=2025-09-14" \
  -H "Authorization: Bearer fade_live_YOUR_KEY_HERE" \
  -o forecasts_nfl_spreads_20250914.json
```

**Export grades for a family as CSV:**

```bash
curl -s "https://fade.sportshack.ai/api/v1/download?dataset=grades&format=csv&family=nfl_spreads&date=2025-09-14" \
  -H "Authorization: Bearer fade_live_YOUR_KEY_HERE" \
  -o grades_nfl_spreads_20250914.csv
```

**Export all forecasts across a full family (no date filter):**

```bash
curl -s "https://fade.sportshack.ai/api/v1/download?dataset=forecasts&format=csv&family=nba_totals" \
  -H "Authorization: Bearer fade_live_YOUR_KEY_HERE" \
  -o forecasts_nba_totals_all.csv
```

## Error: Row Cap Exceeded

If your filter combination would return more than 50,000 rows, the API returns a `422` with the following error envelope. Add or tighten your `family` and `date` filters and retry.

```json
{
  "error": {
    "code": "row_cap_exceeded",
    "message": "Your request would return more than 50,000 rows. Add or narrow your family and date filters and try again."
  },
  "api_version": "1"
}
```
