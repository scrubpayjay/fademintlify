---
title: "GET /forecasts — List Issued Forecast Probabilities"
sidebarTitle: "Forecasts"
description: "Page through all current non-superseded Sportshack forecast probabilities, ordered newest-first, with optional filters for sport, family, and game date."
---

The `/forecasts` endpoint returns the full set of current, non-superseded forecast records Sportshack has issued — one row per active proposition. Results are ordered by `created_at` descending, then `forecast_id` descending, so the most recently issued forecasts always appear first. Each record carries the probability estimate (`p_yes`), model provenance fields, the market and venue identifiers needed to join to your own catalog, and timing metadata about when inputs were captured and when the forecast was issued. Venue prices, bid/ask spreads, and market lifecycle state are never included.

<Note>
  Forecast records reflect Sportshack-issued probability estimates only. Venue prices and market open/close state are not included in any field and are not available through the Quant Partner API.
</Note>

## Query Parameters

<ParamField query="sport" type="string" optional>
  Filter to forecasts for a specific sport, for example `"nfl"` or `"nba"`. Matches the `sport` field on Forecast objects. Omit to return forecasts across all sports.
</ParamField>

<ParamField query="family" type="string" optional>
  Filter to a specific prediction family, for example `"nfl_spreads"`. Values match the `family` field on Forecast objects and the `families` array from `/manifest`. Omit to return forecasts across all families.
</ParamField>

<ParamField query="date" type="string" optional>
  Filter to forecasts whose `inputs_as_of` timestamp falls on the given UTC calendar date. Format: `YYYY-MM-DD`, for example `"2025-09-14"`. This corresponds to the game date in most families. Omit to return forecasts across all dates.
</ParamField>

<ParamField query="limit" type="integer" optional>
  Number of records per page. Accepts integers from `1` to `200`. Defaults to `50`.
</ParamField>

<ParamField query="cursor" type="string" optional>
  Opaque pagination cursor from a previous response's `next_cursor` field. Omit on the first request.
</ParamField>

## Response Fields

<ResponseField name="api_version" type="string">
  Always `"1"`.
</ResponseField>

<ResponseField name="data" type="object[]">
  Array of Forecast objects. Returns an empty array if no forecasts match the filters.

  <Expandable title="Forecast object fields">
    <ResponseField name="forecast_id" type="string (uuid)">
      Sportshack's stable UUID for this forecast record. Use this to look up full provenance details via `GET /forecasts/{forecastId}`.
    </ResponseField>
    <ResponseField name="proposition_id" type="string">
      Identifier for the specific proposition this forecast covers, such as a spread line or total threshold.
    </ResponseField>
    <ResponseField name="market_id" type="string (uuid)">
      The Sportshack market UUID this forecast is attached to. Join to `/markets` for classification metadata.
    </ResponseField>
    <ResponseField name="family" type="string | null">
      Sportshack prediction family, for example `"nfl_spreads"`. `null` for unclassified markets.
    </ResponseField>
    <ResponseField name="threshold" type="number | null">
      The numeric threshold (line or total value) this forecast is evaluating, for example `-3.5`. `null` for families where the proposition is binary and has no numeric threshold.
    </ResponseField>
    <ResponseField name="operator" type="string | null">
      The comparison direction for `threshold`, for example `"greater_than"` or `"less_than_or_equal"`. `null` when `threshold` is `null`.
    </ResponseField>
    <ResponseField name="p_yes" type="number">
      The model's probability estimate that the YES outcome resolves, expressed as a decimal between `0` and `1` inclusive, for example `0.62`.
    </ResponseField>
    <ResponseField name="model_id" type="string">
      Identifier for the model that produced this forecast, for example `"reality-engine-v3"`.
    </ResponseField>
    <ResponseField name="model_version" type="string">
      Semantic version of the model at issuance, for example `"3.4.1"`.
    </ResponseField>
    <ResponseField name="inputs_hash" type="string">
      Fingerprint of the input data set used to produce this forecast. Stable across identical input snapshots; changes when any input value changes.
    </ResponseField>
    <ResponseField name="inputs_as_of" type="datetime | null">
      UTC ISO-8601 timestamp representing the point-in-time of the input data. Corresponds to game date in most families. `null` if not recorded.
    </ResponseField>
    <ResponseField name="issued_at" type="datetime | null">
      UTC ISO-8601 timestamp of when Sportshack issued this forecast. `null` indicates the issuance time is UNKNOWN — the forecast exists but the original issuance timestamp was not captured.
    </ResponseField>
    <ResponseField name="scheduled_start_utc" type="datetime | null">
      UTC ISO-8601 scheduled start time of the underlying event. `null` if not available.
    </ResponseField>
    <ResponseField name="issuance_evidence_source" type="string | null">
      Name of the external data source used to verify issuance, for example `"kalshi_api"`. `null` if not recorded.
    </ResponseField>
    <ResponseField name="issuance_evidence_source_id" type="string | null">
      The identifier within `issuance_evidence_source` that confirms issuance, for example a snapshot ID or trade ID from the venue. `null` if not recorded.
    </ResponseField>
    <ResponseField name="snapshot_id" type="string | null">
      Provenance reference identifying the internal snapshot from which inputs were drawn. The snapshot contents are not redistributed. `null` if not recorded.
    </ResponseField>
    <ResponseField name="venue" type="string | null">
      The prediction venue this forecast is associated with. `null` if not recorded at the forecast level.
    </ResponseField>
    <ResponseField name="venue_market_id" type="string">
      The venue's own identifier for the market this forecast covers.
    </ResponseField>
    <ResponseField name="event_ticker" type="string | null">
      The venue's event grouping ticker. `null` if the venue does not expose an event layer.
    </ResponseField>
    <ResponseField name="created_at" type="datetime | null">
      UTC ISO-8601 timestamp of when this forecast record was written to the Fade database. Used as the primary sort key. `null` in rare historical backfill cases.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="next_cursor" type="string | null">
  Opaque cursor for the next page of results. `null` when you have reached the last page.
</ResponseField>

## Example

**Filter by prediction family:**

```bash
curl -s "https://fade.sportshack.ai/api/v1/forecasts?family=nfl_spreads&limit=25" \
  -H "Authorization: Bearer $FADE_API_KEY"
```

**Filter by family and game date:**

```bash
curl -s "https://fade.sportshack.ai/api/v1/forecasts?family=nfl_spreads&date=2025-09-14" \
  -H "Authorization: Bearer $FADE_API_KEY"
```
